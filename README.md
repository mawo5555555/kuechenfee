# Küchenfee

Persönliche Rezeptsammlung als App (PWA): Rezepte per Link, Kochbuch-Foto, Text oder von Hand sammeln, Portionen umrechnen, kochen mit Timern, Einkaufsliste, Teilen und Backup. Alle Daten bleiben auf dem eigenen Gerät.

Änderungen siehe [CHANGELOG.md](CHANGELOG.md).

## Bedienung
Die ausführliche Schritt-für-Schritt-Anleitung steckt in der App unter **Mehr → Anleitung**.
